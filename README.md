# 🧮 Angular Calculator App

A simple and beginner-friendly calculator built using **Angular 16** with **NgModule-based architecture (no standalone components)**.
This project is created to practice Angular fundamentals and improve real-world development skills.

---

## 🚀 Features

* ➕ Basic operations: Addition, Subtraction, Multiplication, Division
* 🧾 Expression display (e.g., `10 + 5`)
* 🚫 Prevent multiple operators (e.g., `+ +`, `+ *`)
* ⌫ Backspace functionality (smart delete for numbers & operators)
* 🧹 Clear button to reset calculator

---

## 🛠️ Tech Stack

* Angular 16
* TypeScript
* HTML
* CSS
* NgModule (Non-standalone approach)

## ▶️ How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/gautamchauhan1/angular-calculator-app.git
```

2. Navigate to project folder:

```bash
cd angular-calculator-app
```

3. Install dependencies:

```bash
npm install
```

4. Run the app:

```bash
ng serve
```

5. Open in browser:

```
http://localhost:4200
```
